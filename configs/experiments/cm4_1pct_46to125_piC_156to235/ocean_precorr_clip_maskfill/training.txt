# ARM C -- the freshwater test, run without the confound, added 2026-08-24.
#
# The 130-yr and 200-yr standalone rollouts said the maskall win was never about
# completing the mask: every arm that collapses is one that MEAN-FILLS
# sea_surface_fraction, and the only mean-fill arm that survives both scenarios
# is the one that excludes it. maskall vs maskatm differ in exactly that channel
# and differ in whether they collapse; masked count does not order the collapses
# at all (86 -> yr 97, 89 -> yr 29, 96 -> yr 47, 95 -> never).
#
# Why that channel specifically: sea_surface_fraction is geometry, not state --
# its value IS the land/ocean distinction. Mean-fill puts its land cells at the
# normalized value 0, indistinguishable from a real half-ocean coastal cell,
# where fill_value 0.0 puts them far outside the field's range. Which is also
# why both fill_value 0.0 arms are immune regardless of masking scope.
#
# So maskfw inherited a broken sea_surface_fraction from the base exclude list,
# and the freshwater hypothesis has never actually been tested. maskfw had the
# best short-horizon so_0 of any arm (0.111 at its selected epoch) and was the
# FIRST to collapse (rollout yr 29 / 57). This row is maskfw with
# sea_surface_fraction added back to the exclude list -- ONE channel different
# from a known collapse, 88/97 masked against maskfw's 89/97:
#
#   cell                        exclude list                          masked
#   ..._fillmean_maskfw         land_fraction + radiation + wind       89/97
#   ..._fillmean_maskfw_keepssf ^ plus sea_surface_fraction            88/97
#
# Read it as: if this does not collapse, sea_surface_fraction is the driver and
# the freshwater masking is recovered along with it -- which would make this the
# best arm in the protocol on surface salinity. If it still collapses, the
# freshwater masking itself is implicated and the sea_surface_fraction story is
# incomplete.
#
# Same seeding caveat as above: rs0 is a screen. But the readout here is a
# collapse/no-collapse over a 130-200 yr rollout, not a so_0 number, and no seed
# of any arm has ever half-collapsed -- so one seed does carry the qualitative
# result, while the onset year (which does not even reproduce across scenarios)
# does not.

# ARM D -- per-channel fill value. STAGED AT `skip`, NOT LAUNCHED.
#
# Requires ace PR #1458 (feature/per-channel-mask-fill-value), which is on this
# branch as a cherry-pick and is NOT on main. If that PR does not merge, this arm
# cannot run on mainline code. Nothing here touches
# exper/2026-08-18-precorr-optim, which this branch was cut from.
#
# WHY. The standalone rollouts split cleanly by field: mean-fill wins every 2D
# surface field, zero-fill wins the 19-level velocity and temperature profiles by
# 1.2-1.4x. Both directions are real and a single global fill_value cannot express
# them at once. The mechanism is that a masked cell means two different things --
# for sst or salinity it means "no data here", where the channel mean is a neutral
# filler and 0.0 injects a large out-of-range value near coastlines; for a
# depth-resolved channel below the sea floor it means "genuinely dry", which is
# usable information that only an out-of-range marker conveys. Nothing else in the
# inputs states dryness per level: land_fraction is a single 2D field, while the
# wet fraction falls from 0.693 at level 0 to 0.073 at level 18, with 89.4% of
# surface-ocean columns dry by the deepest level.
#
# WHAT. The surviving recipe (fill_value: mean, excluding land_fraction and
# sea_surface_fraction) plus fill_value_overrides sending the four depth-resolved
# families and deptho to 0.0. Resolved and checked against TrainConfig:
#   excluded, never masked   2  land_fraction, sea_surface_fraction
#   fill 0.0                78  deptho, hfgeou + so_/thetao_/uo_/vo_ (4 x 19)
#   fill mean               17  sst, zos, sfdsi, UI, VI, sea ice, forcings
#
# Two judgement calls worth revisiting before launch:
#   - so_0 and thetao_0 are level-0 (surface) but ride the family prefix into
#     zero-fill. mask_0 is bit-identical to mask_2d, so their masked cells are
#     exactly the land cells that sst's are -- the alternative is to add
#     so_0/thetao_0 exact-name entries at "mean". Family uniformity was chosen.
#   - hfgeou is zero-filled, at elynn's call. It is NaN on land like deptho and is
#     a sea-floor boundary field, so it belongs with the depth group rather than
#     the surface set despite being 2D.
#
# READ IT AS: against ..._fillmean_maskall (rs0/1/2), which is identical except
# for the overrides. If the interior profiles improve toward the zero-fill arms
# while the surface fields hold, per-channel fill is worth keeping. If nothing
# moves, the surface/interior split is not about the fill value and the feature
# should not merge on this evidence.
