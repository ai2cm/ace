#

#

# not a measurement: across-seed CV in this protocol is 0.2-0.9% on
# val_1pct_late and 3-5% on the inference nrmse, but 14-29% on so_0. So a
# single seed can only read a so_0 effect of roughly 40-60%+ (the 1deg maskall

# comparison in particular is a difference-of-differences and cannot be settled
# at one seed each.
#
# To promote an arm to 3 seeds: first flip its rs0 `train` -> `training`, THEN
# flip its rs1/rs2 `skip` -> `train`. The runner only reads this file and never
# writes it back, so an rs0 row left at `train` relaunches rs0 alongside the new
# seeds.

# ARM B -- decomposing the maskall change over the fillmean side, added
# 2026-08-21. The maskall cell above moves two things at once: the ten
# atmosphere forcings become masked AND sea_surface_fraction becomes unmasked.
# These two rows split that, and split the forcings by what they carry:
#
#   cell                    exclude list                       masked
#   ..._fillmean            land_fraction + 10 forcings         86/97
#   ..._fillmean_maskfw     ^ minus LHTFLsfc, PRATEsfc,          89/97
#                            total_frozen_precipitation_rate
#   ..._fillmean_maskatm    [land_fraction]                     96/97
#   ..._fillmean_maskall    [land_fraction, sea_surface_fraction] 95/97
#
# so (maskfw - fillmean) = the freshwater channels, (maskatm - maskfw) =
# radiation + wind stress, (maskall - maskatm) = the sea_surface_fraction flip.
# The hypothesis under test is that the freshwater trio carries most of the
# so_0 effect: surface salinity is the one field whose forcing the network must
# infer from the atmosphere channels and whose budget no corrector pins, so
# land-side evaporation and precipitation are the values it should not be able
# to read across the mask edge.
#
# Same seeding caveat as above: one seed reads only a ~40-60% so_0 effect, and
# a decomposition splits the effect, so only "the freshwater trio reproduces
# most of maskall" is readable at rs0. rs1/rs2 staged at skip.
