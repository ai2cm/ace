#
# stepper_training.corrector_loss.precorrector_optimization is NOT carried by
# that merge -- it lives outside .stepper -- so it stays in the template. It is

#
# The row's three overrides:
#   seed=0                                  the template has no seed key
#   ...ocean_heat_content_correction.method belt-and-braces; already in the
#                                           checkpoint config
#   ...corrector_disabled_epochs=0          1 -> 0, a deliberate change. The
#     pretraining's one-epoch warm-up let a from-scratch network learn before
#     the corrector engaged. The trainer restarts its epoch counter on a
#     fine-tune (trainer.py: stepper.set_epoch(self._epochs_trained + 1), and

#     carrying the 1 through would train epoch 1 of 10 uncorrected from an
#     already-converged checkpoint and let best_ckpt select on it.

# unclipped, and the template carries train-config.yaml's optimization block
