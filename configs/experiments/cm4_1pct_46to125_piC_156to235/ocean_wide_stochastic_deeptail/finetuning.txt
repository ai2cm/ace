# at equal epochs. See finetune-config-template.yaml for why.
#
# Forked from the stage-1 checkpoints, NOT resumed from the long-tail wave's
# stage-2 checkpoints. Resuming would confound the schedule change with 12
# extra epochs of training; forking keeps schedule the single axis across all
# three waves, which all start from the same four best_ckpts.
#
# Runs in PARALLEL with the long-tail extension: that wave resumes its own
# stage-2 result datasets (see ../ocean_wide_stochastic_longtail/resuming.txt)
# while this one reads the stage-1 result datasets, which are finalised and
# immutable. Neither wave waits on the other.
#
# Its own config directory because uncoupled_finetune.sh writes
# finetune-config.yaml into the directory it reads -- three waves from one
# directory would clobber each other's config mid-launch.
#
# Same four seeds as both prior waves, deliberately: paired comparison rather
# than three independent screens. Both rs2 seeds stay held to match, even
# though allblocks rs2 (uajyh7lf) finished pretraining on 2026-09-03 and the
# original reason for holding them is gone -- two seeds per injection point is
# what the other two waves carry, and unbalancing the arms would cost more in
# comparability than a third seed buys.
#
# Read on inference_piC/time_mean_norm/rmse/channel_mean, against the
# long-tail wave's 0.0501-0.0562 at epoch 12, the ERA5 wave's 0.077-0.093, and

# val_piC/mean_norm/weighted_rmse/channel_mean, which is single-member one-step
# RMSE and structurally penalises a CRPS-trained model -- and which the
# long-tail schedule already degrades relative to the ERA5 one (0.256-0.263
# against 0.242-0.243), so a further shift is expected to degrade it again.
# That is the trade being bought, not a fault.
#
# Priority is split rs0 high / rs1 normal, deliberately: eight runs across this
# wave and its sibling would otherwise sit at high simultaneously and crowd the
# rest of the team off jupiter. One seed per group at high guarantees each arm
# produces a readable curve on schedule; the second seed arrives when capacity
# allows and only sharpens the seed spread, which in this protocol has been
# small (the 12-epoch long-tail seeds agree to 0.0003 and 0.0000).
