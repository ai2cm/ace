# ocean_wide_uniformdt_clip
#
# `ocean_wide_ohc_clip` with the ocean heat content correction switched from
# `scaled_temperature` (multiply every level by one global ratio, so heat is
# deposited proportional to T_k * dz_k) to `uniform_temperature` (add one global
# increment to every level, so heat is deposited proportional to dz_k). Every
# other term -- architecture, data, `optimization.max_grad_norm=1.0`, the 4-step
# unroll, the post-corrector loss -- is held fixed, so this row and the
# `ocean_wide_ohc_clip` rows above differ in exactly the corrector's functional
# form. Motivation: research investigation on how the corrector places its
# temperature adjustment; the multiplicative form's corrected output is
# invariant under rescaling the network's raw temperature output, which leaves
# the amplitude unconstrained by a post-corrector loss, and the additive form
# has no such invariance.

# ocean_wide_uniformdt_hybridresid_clip -- Troy's hybrid-residual stepper
# (ace #1487) on our uniform-dT recipe, with sst residual as well as thetao_*.
#
# residual_prediction restricts the residual path to the named prognostics and
# leaves the other 67 channels full-field; residual_normalized_prediction makes
# the network emit those tendencies in normalization.residual units, so a unit
# output is one tendency std. Per #1487 the loss normalizer follows the same
# per-variable convention, which is where the reweighting comes from -- hence NO
# stepper_training.loss.weights on this row: the normalizer replaces them.
#
# The reweighting this implies on our stats is (full-field std / residual std)^2
# per channel: 666x for sst, 729x at thetao_0, 4048x at thetao_12 and 154914x at
# thetao_18 -- bottom-heavy, spanning 212x across the column, against a flat 64x
# in the tw8 arm. Troy's dataset spans 74x with a 28948x maximum, so ours is the
# more aggressive version of the same shape. See the task for the discussion.
#
# Everything else matches ocean_wide_uniformdt_clip exactly: same shared
# train-config.yaml, same uniform_temperature corrector, same max_grad_norm,
# same 4-step unroll, same 75 epochs, no precorrector_optimization and no
# corrector regularization.

# ocean_wide_uniformdt_hybridresid_noclip -- the diagnostic retry of the arm
# cancelled at epoch 21, whose free-running rollout degraded 0.5011 (ep10) ->
# 1.5874 (ep21) while the baseline improved to 0.0905.
#
# Troy's hybrid and full-residual runs both set max_grad_norm: None; ours ran
# 1.0, and that is the ONLY optimizer-level difference from his setup (same
# AdamW, lr 1e-4, weight_decay 0.01, no scheduler, no AMP, same EMA). With the
# residual normalizer multiplying temperature-channel losses by 666-154914x, a
# clip at 1.0 plausibly binds every step, which turns the update into the
# unit-norm direction set by whichever channels dominate -- the deep levels.
#
# max_grad_norm is 1e9 rather than null on purpose: clip_grad_norm_ computes the
# pre-clip norm as a by-product, and ace #1482 logs it as `grad_norm`, but only
# when clipping is configured. 1e9 is far above any plausible norm, so no
# clipping occurs while the norm is still measured -- and it tells us
# retroactively whether 1.0 was binding in the cancelled run. Self-validating:
# if the logged grad_norm ever approaches 1e9 the run was clipped after all.
