# ocean_wide_uniformdt_clip
#
# `ocean_wide_ohc_clip` with the ocean heat content correction switched from
# `scaled_temperature` (multiply every level by one global ratio, so heat is
# deposited proportional to T_k * dz_k) to `uniform_temperature` (add one global
# increment to every level, so heat is deposited proportional to dz_k). Every
# other term -- architecture, data, `optimization.max_grad_norm=1.0`, the 4-step
# unroll, the post-corrector loss -- is held fixed, so this row and the
# `ocean_wide_ohc_clip` rows above differ in exactly the corrector's functional
# form. Motivation: research investigation on how the corrector places its
# temperature adjustment; the multiplicative form's corrected output is
# invariant under rescaling the network's raw temperature output, which leaves
# the amplitude unconstrained by a post-corrector loss, and the additive form
# has no such invariance.

#

# leaves the other 67 channels full-field; residual_normalized_prediction makes
# the network emit those tendencies in normalization.residual units, so a unit

# more aggressive version of the same shape. See the task for the discussion.
#
