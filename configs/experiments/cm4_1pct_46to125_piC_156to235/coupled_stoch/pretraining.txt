# The ocean stays a DETERMINISTIC Samudra. The two ensemble members differ
# because the frozen stochastic ACE2S hands the ocean two different forcings,
# so EnsembleLoss's internal (spread) term is non-zero without any noise
# injected into Samudra itself. This is exactly James's owc_a2s setup, so the
# row below is a strict ONE-VARIABLE fork of cghk183p: only the ocean init
# changes, MSE-pretrained -> MAE-pretrained.
#
# Why an MAE pretrain is the right initialization for this loss: CRPS at one
# member IS MAE, so EnsembleLoss is MAE plus a spread term. An MAE pretrain is
# the deterministic limit of the coupled loss, and coupled FT then only

# family. That is Chris's "less of a shock", and it needs no architecture
