Climate Model Emulation Workshop

CSU / Ai2 ACE Workshop Notebooks

Welcome! These are the notebooks from the climate model emulation workshop at CSU on May 14–15, 2026. Everything has been adjusted to run on the free resources (T4 GPUs) on Google Colaboratory. You can also download the notebooks and assets from HuggingFace to run locally on your own infrastructure.

GitHub Documentation HuggingFace

How to use these notebooks

  1. Click any Open in Colab button below.
  2. Sign in with your Google account if prompted.
  3. Set Runtime → Change runtime type to the T4 GPU (or a higher-end GPU for faster results if you have credits available).
  4. Run it as you would any Jupyter notebook.
